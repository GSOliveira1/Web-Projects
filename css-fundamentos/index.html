CSS - Cascating Style Sheet

O que é o CSS?

O CSS é o responsável pela estilização da página web. Você pode fazer diversas coisas com o CSS, como formatar botões, mudar a cor de fundo da página, cor de fonte, posicionamento de elementos, etc.

Conceitos Importantes

Todos os elementos HTML, quando você for aplicar uma formatação utilizando CSS, pense neles como uma caixa.

Formatações que podemos utilizar:

Caixas:

  • Largura e altura
  • Bordas (cor, espessura e estilo)
  • Cores e imagens de fundo
  • Posição na janela do navegador

Texto:

  • Fonte
  • Tamanho
  • Cor
  • Itálico, negrito, maiúscula

A CSS funciona associando regras aos elementos HTML. Essas regras determinam como o conteúdo dos elementos especificados deve ser exibido.

Uma regra CSS contém duas partes: um seletor e uma declaração. O seletor indica qual elemento será formatado, e a declaração aplica a formatação.

Exemplo:

p{color: red;}

Como aplicar CSS?

Existem três formas de aplicar CSS em sua página web: inline, interna e externa.

  • Inline: aplicado diretamente no elemento que você deseja formatar. Usado geralmente quando você deseja fazer uma formatação específica apenas naquele elemento.
  • Internal: dentro de um <style>...</style> declarado na <head> da sua página
  • External: em um arquivo separado, de formato.css. Para que a formatação seja aplicado, é necessário fazer um link na <head> para o arquivo contendo a estilização da página.

Div e Span

Permitem agrupar conjuntos de elementos no seu site.

Div é um elemento de bloco. Elementos de bloco sempre iniciam em uma nova linha na janela do navegador. Outros exemplos são: <h1>, <p>, <ul>, <li>.

Já o span é um elemento de linha. Elementos de linha aparecem um ao lado do outro na janela do navegador. Outros exemplos são: <img>, <a>, <strong>, <em>.

O elemento <div> permite agrupar um conjunto de elementos em uma caixa de nível de bloco.

O elemento <span> funciona como um equivalente em linha do <div>.

  • é usado geralmente para conter uma seção de texto em que não há nenhum outro elemento adequado para diferenciá-lo do texto adjacente.

Nem todas as divs serão formatadas da mesma maneira. Para fazer formatações em elementos específicos, podemos utilizar classes e ids.

Cores

Cada cor em um computador é criada misturando quantidades de vermelho(R), verde(G) e azul (B). RGB.

Maneiras de representar cores:

  • Nomes de cores: red, green, blue
  • RGB: valores para vermelho, verde, azul são expressos em números entre 0 e 255
  • Códigos hexadecimais: represantam os valores para vermelho, verde e azul no código hexadecimal.
  • HSL: valores de matiz, saturação e luminosidade. Os valores de saturação e luminosidade são expressos em porcentagem (%). Saturação é a quantidade de cinza em uma cor, e a luminosidade é a quantidade de branco (claridade) ou preto (sombra) em uma cor.

Fontes

Serifa

Fontes com serifa têm detalhes adicionais na extremidade dos traços principais das letras, esses detalhes são conhecidos como serifas.

Exemplos

  • Georgia
  • Times
  • Times New Roman

Sem serifa

Fontes sem serifa contêm extremidades retas, tendo um design mais limpo.

Exemplos

  • Arial
  • Verdana
  • Helvetica

Monoespaçada

Cada letra em uma fonte monoespaçada tem a mesma largura, fontes não monoespaçadas têm larguras específicas.

Exemplos

  • Courier
  • Courier New

Cursiva

Fontes cursivas têm traços de junção ou outras características cursivas, como estilos manuscritos.

Exemplos

  • Comic Sans MS
  • Monotype Corsiva

Fantasia

Fontes fantasia costuma ser fontes decorativas e são muito usadas para títulos. Não são projetadas para textos longos.

Exemplos

  • Haettenschweiler
  • Mythshire

Modelo de Caixa

Cada caixa tem uma borda, mesmo que não esteja visível.

Padding: padding/preenchimento é o espaçamento entre a borda de uma coisa e qualquer coisa que esteja dentro dela.

Margin: contornam e delimitam as extremidades, criando espaços entre elementos diferentes.

Podemos colocar bordas, margin e padding em direções específicas: top, right, bottom, left (EXATAMENTE NESSA ORDEM).

Bordas

Bordas possuem por padrão 3 valores:

  • Espessura: border-width
  • Cor: border-color
  • Estilo de borda: border-style

É possível arredondar bordas utilizando o border-radius.

Podemos formatar definindo: 4 valores (top, right, bottom, left), 2 valores (top/bottom, right/left) e 1 valor (aplica para todos os lados).

Classes e IDs

ID é um atributo utilizado para diferenciar um elemento dos mais. Cada ID é único. Geralmente é utilizado para estilizar cabeçalho, rodapé, e scripts JS.

Classes é um atributo que define um grupo de elementos. Geralmente é utilizado em itens que se repetem, como botões, cards e itens de lista.

Cascata e herança

Especificidade define o que vai ser feito primeiro em uma regra CSS.

Efeito cascata: se o CSS encontra outra formatação para um mesmo elemento, ele aplica a última formatação encontrada.

Herança: elementos filhos herdam de seus pais. Formatações aplicadas diretamente nos filhos sobrescrevem as herdadas dos pais.

Unidades de medida CSS

Medidas absolutas

  • cm -> centímetros
  • mm -> milímetros
  • in -> polegadas
  • px -> pixel. MAIS USADA
  • pt -> ponto
  • pc - paica

Medidas relativas

  • em -> relativo ao tamanho da fonte do pai
  • rem -> relativo ao tamanho do elemento raiz
  • % -> relativo ao tamanho do elemento pai. 100% é a largura do elemento parente
  • vw -> relativo a largura total da tela
  • vh -> relativo a altura total da tela

Formatações de texto

  • font-weight: deixar o texto em negrito. -> normal, bold
  • font-style: estilo do texto. -> normal, italic e oblique
  • text-transform: transforma o texto. -> uppercase, lowercase, capitalize
  • text-decoration: decora o texto. -> underline, overline, line-through, none(usado em links)
  • line-height: define o espaçamento vertical entre as linhas do texto.
  • letter-spacing: define o espaçamento entre as letras do texto.
  • word-spacing: define o espaçamento entre as palavras do texto.
  • text-indent: indenta o texto.
  • text-align: alinhamento do texto (por padrão é alinhado à esquerda).

Cores e Imagens de Fundo

Para mudar o background de uma página web, podemos utilizar:

  • background-color: altera a cor
  • background-image: url() -> bota uma imagem de fundo. Por padrão, se a imagem for menor do que a caixa, ela irá se repetir para preencher o background.
    • background-repeat:
      • repeat: valor padrão
      • repeat-x: repete horizontalmente
      • repeat-y: repete verticalmente
      • no-repeat: não repete
  • background-attachment:
    • fixed: a imagem de fundo permanece na mesma posição na página
    • scroll: a imagem de fundo se move com o conteúdo quando o usuário rola a página
  • background-position: permite que você alinhe os conteúdos
    • horizontal: left, center, right
    • vertical: top, center, bottom

Mais sobre Seletores

  • Seletor universal: *{...} -> aplica em todos os elementos da página
  • Seletor de filho: elemento>filho{...} -> seleciona o primeiro elemento que é filho do outro.
  • Seletor de descendente: elemento1 elemento2{...} -> seleciona um elemento que é descendente de outro elemento especificado.
  • Seletor de irmão: elemento1 + elemento2{...} -> seleciona o primeiro elemento2 após qualquer elemento1.

Pseudo-classes e pseudo-elementos

Pseudo-classes: é uma palavra-chave adicionada a seletores, que permite que você estilize uma parte específica do elemento selecionado.

Links

  • a:hover -> passar o cursor sobre o link
  • a:visited -> links visitados
  • a:links -> links não visitados
  • a:active -> quando você clica no link

Forms

  • input:checked -> quando você marca a opção
  • input:focus -> quando você seleciona uma caixa de texto
  • input:required -> para input com atributo required

Textos

  • p::first-line -> primeira linha
  • p::first-letter -> primeira letra
  • p::selection -> quando você seleciona o texto

Herança e Especificidade

Os elementos irão herdar formatações dos seus elementos pais. Porém, algumas formatações, como background e border, não são herdadas.

Especificidade: é a maneira de como os navegadores definem quais valores de propriedades são os mais relevantes para o elemento a ser utilizado. Especificidade é baseada apenas nas regras impostas na composição de diferentes tipos de seletores.

Ordem de aplicação de formatação:

  1. Regras com !important
  2. Seletores mais específicos
  3. Última regra processada

Seletores mais específicos:

  1. Estilo inline
  2. IDs
  3. Classes, atributos e pseudo-classes
  4. Elementos e pseudo-elementos.
