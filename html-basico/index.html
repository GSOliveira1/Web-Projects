Tags de cabeçalho e parágrafos

As tags reponsáveis pelo cabeçalho da página são: <h1>, <h2>, <h3>, <h4>, <h5> e <h6>. A tag <h1> representa a maior e a <h6> representa a menor.

Os parágrafos são representados pela tag <p>

Sempre há um espaçamento entre um parágrafo e o elemento posterior a ele, sem a necessidade de adicionar a tag <br> (quebra de linha).

As tags responsáveis por formatação de texto são:

  • <b>: negrito. Exemplo: Negrito.
  • <strong>: negrito. Exemplo: Use este preferencialmente.
  • <i>: itálico. Exemplo: Itálico
  • <em>: ênfase. Exemplo: Ênfase.
  • <mark>: marca texto. Exemplo: Texto marcado
  • <small>: texto menor. Exemplo: Pequeno
  • <del>: texto deletado. Exemplo: Deletado
  • <ins>: texto inserido. Exemplo: Olá.
  • <sub>: texto subescrito. Exemplo: H2O
  • <sup>: texto superescrito. Exemplo: X2

Lista Ordenadas e Não-Ordenadas

Para criar uma lista não ordenada, utiliza-se a tag <ul>. Dentro da tag da lista não ordenada, utilizamos a tag <li> para listar os itens da lista. Exemplo:

  • Item 1
  • Item 2
  • Item 3

Para criar uma lista ordenada, utiliza-se a tag <ol>. Dentro da tag da lista ordenada, utilizamos a tag <li> para listar os itens da lista. Exemplo:

  1. Item 1
  2. Item 2
  3. Item 3

Para mudar o tipo de contagem da lista ordenada, podemos usar o style="list-style-type: ". Exemplo:

  1. Item 1
  2. Item 2
  3. Item 3

Meta Tags em HTML

As meta tags em html fornecem metadados sobre uma página web. Elas são declaradas dentro da seção <head> do documento HTML e não são visíveis na página. São usadas pelos navegadores, ferramentas de pesquisa e plataformas de redes sociais para entender e processar o conteúdo da página corretamente. As tags mais comuns e importantes são:

  • charset: especifica a codificação dos caracteres do documento, garantindo que os símbolos são exibidos corretamente.
  • description: fornece uma pequena descrição do conteúdo da página. Geralmente é usado por ferramentas de pesquisas.
  • viewport: essencial para o design responsivo, controla como que a págins escala e apresenta em diferentes dispositivos.
  • author: especifica o autor da página web.
  • robots: dá instruções aos crawlers de pesquisa sobre como indexar a página e seguir seus links.

Utilizando Imagens em HTML

Para adicionar imagens em nossa página web, utiliza-se a tag <img>. A estrutura padrão da tag é:

<img src="" alt="">

Onde em "src" você coloca o caminho para o diretório ou URL da imagem, e "alt" representa uma alternativa caso a imagem não carregue corretamente.

É possível utilizar um style para alterar o tamanho (altura e largura) da imagem, ou usar os atributos width e height diretamente.

Utilizando Links

Um link é responsável por te levar a uma outra página do site. Para adicionar um link, utiliza-se a tag <a>:

<a href="">...</a>

Onde o atributo href é responsável pelo link. Se for uma referência a um site externo, você precisa colocar o endereço completo (URL).

Para que o link seja aberto em uma nova guia do navegador, é preciso adicionar o atributo target="_blank".
