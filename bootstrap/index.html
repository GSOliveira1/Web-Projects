Introdução

O Bootstrap segue uma lógica Mobile First: no design responsivo, começa desenvolvendo para dispositivos menores e depois para dispositivos maiores.

Design responsivo: o design da página responde ao tamanho do dispoitivo em que ele está sendo visto (celular, tablet, notebook, TV).

O Bootstrap possui inúmeros designs prontos, e é muito utilizado nos dias atuais, mesmo que haja outras tecnologias fortes no mercado.

Globais Importantes

O Bootstrap precisa que o arquivo seja HTML5. Sem isso, os estilos não funcionam corretamente.

É preciso definir uma viewport meta tag.

Box sizing: o box sizing é definido como border box. Isso garante que o padding não afete a largura final computada de um elemento.

Breakpoints

Breakpoints, ou pontos de quebra, são larguras costumizáveis que determinam como o layout responsivo da sua página web irá comportar em diversos dispositivos.

São manipulados nas medias queries, que são elementos CSS.

Breakpoints do Bootstrap:

Breakpoint Class Infix Dimensions
Extra small none < 586px
Small sm ≥ 576px
Medium md ≥ 768px
Large lg ≥ 992px
Extra large xl ≥ 1200px
Extra extra large xxl ≥ 1400px

Você pode definir seus próprios breakpoints customizáveis através das media queries.

Containers

Os containers são o elemento mais básico no Bootstrap e são necessários quando for utilizar o sistema padrão de Grid e Flexbox.

Bootstrap possui três tipos de containers:

  • container: responsiva, com largura fixada, onde a largura máximo do container muda a cada breakpoint.
  • container-breakpoint: quando ele atinge o breakpoint específico, a width muda para 100%, ocupando todo o espaço disponível.
  • container-fluid: width = 100% em todos os breakpoints.

Posicionamentos

Elementos Flutuantes:

  • float-<direção> (start e end)
  • Responsivo:
    • float-<breakpoint>-<direção>
    • breakpoints: sm, md, lg, xl, xxl
    • direção: start, end
  • class="clearfix": arruma o clear dos elementos flutuantes
  • Fixed, sticky, absolute também possuem classes que simplificam a utilização deles.

Margin e Padding

Margin

  • mt -> margin top
  • mb -> margin bottom
  • ms -> margin start (esquerda)
  • me -> margin end (dirita)
  • mx -> margin no eixo X (horizontal)
  • my -> margin no eixo Y (vertical)
  • m -> margin em todos os lados
  • valor -> 1 a 5

Padding

  • pt -> padding top
  • pb -> padding bottom
  • ps -> padding start (esquerda)
  • pe -> padding end (dirita)
  • px -> padding no eixo X (horizontal)
  • py -> padding no eixo Y (vertical)
  • p -> padding em todos os lados
  • valor -> 1 a 5

Tamanhos e Bordas

Classes de Largura

  • class="w-25" = width: 25%
  • class="w-50" = width: 50%
  • class="w-75" = width: 75%
  • class="w-100" = width: 100%
  • class="w-auto" = largura automática, preenche todo o espaço disponível

Classes de Altura

  • class="h-25" = height: 25%
  • class="h-50" = height: 50%
  • class="h-75" = height: 75%
  • class="h-100" = height: 100%
  • class="h-auto" = altura de acordo com o conteúdo

Bordas

  • border: todas as bordas
  • border-top: borda superior
  • border-bottom: borda inferior
  • border-end: borda direita
  • borda-start: borda esquerda
  • Para definir cores, utilizamos o border-<cor>
  • Para arredondar as bordas, temos as seguintes opções: rounded, rounded-top, round-start, rounded-end, rounded-circle

Barras de Navegação

Informações importantes sobre navbars

A navbar e seus conteúdos são fluidos por padrão. É preciso mudar o container caso queira modificar a largura da navbar.

Utilize a tag <nav> para garantir acessibilidade em seu site.

As navbars são responsivas por padrão.

Indica o item (página) atual utilizando aria-current: "page".

As navbars vem com uma varidade de componentes que o bootstrap oferece:

  • .navbar-brand: utilizado para colocar logo/nome. Funciona melhor em elementos <a>
  • .navbar-nav: para navegação com altura máxima e leve.
  • .navbar-toggle: utilizado com o plugin de collapse.
  • .active: utilize para indicar a página atual.

Paginação

O bootstrap utiliza links para fazer paginação no site. Paginação é feita utilizando listas para que leitores de tela possam anunciar o número de links disponíveis. Utilize um <nav>.

Como a maioria das páginas possuem mais que uma navegação, é recomendado adicionar uma aria-label ao <nav> da paginação para refletir o seu propósito.

Você vai utilizar as classes: .pagination na <ul>, .page-item no <li> e .page-link no <a>.

Cards

Um card é um container flexível, contendo opções para header, footer, diferentes conteúdos, backgrounds e opções de display. Eles são construídos utilizando flexbox, oferecendo fácil alinhamento e mistura com outros elementos do Bootstrap.

Para criar um card, utilizamos a classe .card em uma div.

Utilizamos a classe .card-body quando queremos um conteúdo com padding dentro do card.

Títulos de card podem ser adicionados utilizando a classe .card-title. Sub-títulos são adicionais utilizando a classe .card-subtitle Textos podem ser adicionais utilizando a classe .card-text.

.card-img-top e .card-img-bottom arredondam as bordas superior e inferior da imagem respectivamente para ficarem de acordo com a margem do card.

Cards não assumem nenhuma largura para iniciar, então o padrão é width = 100%.
