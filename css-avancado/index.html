Posicionamento

Cada elemento de nível de bloco aparece numa nova linha, fazenco com que cada item apareça um embaixo do outro, mesmo que você defina uma largura e tenha espaço para ficar um ao lado do outro, eles não ficarão.

Posicionamento relativo: move um elemento da posição que ele estaria no fluxo normal, deslocando para a parte superior, inferior, esquerda ou direita de onde ele seria posicionado.

Posicionamento absoluto: posiciona o elemento em relação a seu elemento contêiner/pai. Elementos posicionados de forma abosluta movem-se a medidade que o usuário rola a página para cima e para baixo.

Posicionamento fixo: é uma forma de posicionamento absoluto que posiciona um elemento em relação a janela do navegador. Não afetam a posição de elementos próximos e não se movem quando o usuário rola para cima e para baixo.

Para indicar onde uma caixa deve ser posicionada, você deve usar propriedades de deslocamento de caixa para informar ao navegador quanto você quer posicionar essa caixa: top, right, bottom e left

Elementos Flutuantes

Fazer um elemento flutuar permite remover esse elemento do fluxo normal e posiciona-lo mais a esquerda ou mais a direita de uma caixa contêiner.

Muitos layouts posicionam caixas lado a lado e você pode fazer isso usando elementos flutuantes. Entretanto, normalmente utilizamos grid e flexbox para criar estrutura de sites profissionais.

Se você manda todos os elementos flutuarem para a esquerda (float: left), os elementos ficarão um do lado do outro.

Quando os elementos não cabem mais um do lado do outro, na mesma linha, os próximos elementos serão jogados para a linha de baixo.

Mais Tags

Existem tags que são utilizadas para melhorar a legibilidade do código e permite melhor organização dos conteúdos no seu site. Essas tags são:

  • <header> -> cabeçalho
  • <nav> -> barra de navegação
  • <main> -> conteúdo principal
  • <footer> -> rodapé
  • <article> -> postagens, notícias, artigos
  • <section> -> seções, bom para organização
  • <time> -> identifica tempo/data
  • <aside> -> área complementar ao conteúdo principal.

Para o usuário final, a utilização dessas tags não faz muita diferença. O principal motivo para utilizar elas é que os buscadores dos navegadores serão beneficiados pelo seu uso.
