Posicionamento

Cada elemento de nível de bloco aparece numa nova linha, fazenco com que cada item apareça um embaixo do outro, mesmo que você defina uma largura e tenha espaço para ficar um ao lado do outro, eles não ficarão.

Posicionamento relativo: move um elemento da posição que ele estaria no fluxo normal, deslocando para a parte superior, inferior, esquerda ou direita de onde ele seria posicionado.

Posicionamento absoluto: posiciona o elemento em relação a seu elemento contêiner/pai. Elementos posicionados de forma abosluta movem-se a medidade que o usuário rola a página para cima e para baixo.

Posicionamento fixo: é uma forma de posicionamento absoluto que posiciona um elemento em relação a janela do navegador. Não afetam a posição de elementos próximos e não se movem quando o usuário rola para cima e para baixo.

Para indicar onde uma caixa deve ser posicionada, você deve usar propriedades de deslocamento de caixa para informar ao navegador quanto você quer posicionar essa caixa: top, right, bottom e left

Podemos centralizar uma <div> utilizando posicionamento absoluto:

  • position: absolute;
  • top: 50%;
  • left: 50%;
  • transform: translate(-50%, -50%)
